# Dossier d'images

Déposez ici vos propres images : elles apparaissent alors dans la liste
« Exemple des TP » de l'interface web et dans la sélection automatique de
l'application de bureau.

L'application cherche aussi des images dans les dossiers `TP1/` … `TP7/` du
dépôt parent, ce qui permet de réutiliser directement les images des travaux
pratiques (images bruitées du TP7, cellules, pièces de monnaie, photographies
des TP1 à TP4) sans rien copier.

Formats reconnus : `jpg`, `jpeg`, `png`, `bmp`, `tif`, `tiff`, `webp`, `ppm`,
`pgm`.
